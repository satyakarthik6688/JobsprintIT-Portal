Job Description

We are looking for a motivated Java Developer to join our software development team. The candidate will work on developing, testing and maintaining Java-based applications.

This opportunity is suitable for freshers and early-career developers who have a strong understanding of Java programming and database fundamentals.

Responsibilities

  • Develop and maintain Java applications.
  • Write clean and maintainable code.
  • Work with developers to implement new features.
  • Identify and fix software issues.
  • Participate in application testing and debugging.
  • Work with SQL databases for application data.

Requirements

  • Bachelor's or Master's degree in Computer Science or related field.
  • Knowledge of Core Java and OOP concepts.
  • Basic knowledge of SQL and relational databases.
  • Understanding of software development concepts.
  • Good problem-solving and communication skills.

Required Skills

Java OOP SQL MySQL JDBC Git Problem Solving
